# File System Representation Using Graph

## Aim
To represent a file system using an adjacency matrix
and search for files using BFS and DFS.

## Language
C

## Algorithms
1. Breadth-First Search (BFS)
2. Depth-First Search (DFS)

## Concepts Used
- Graph
- Adjacency Matrix
- Queue
- Recursion

## Files
- filesystem.c - C program
- sample_output.txt - Sample input and output

## How to Compile
gcc filesystem.c -o filesystem

## How to Run
./filesystem

## Result
The program displays BFS and DFS traversal orders
and reports whether the specified file is found.
